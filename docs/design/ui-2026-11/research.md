# 设计研究：Mathnim 下一代界面（2026-11-02）

先想清楚产品为什么存在，再谈它长什么样。

## 0. 产品的目的，和人在里面怎么走

Mathnim 的唯一标准是“讲明白”：学习者能用自己的话讲给别人听，知道什么时候用。
它的主要资产是**会动的图**，图就是讲解本身。其次是边栏里的导师：卡住时就在原地问。

人在产品里只沿一条主路走：

| 地方 | 做什么 | 停留 |
|---|---|---|
| 首页（门厅） | 一步回到上次的位置；或者挑一门课 | 几秒 |
| 课程页（前厅） | 看清这门课讲什么、有多大、我走到哪了；开始或继续 | 几十秒 |
| 课时（房间） | 一页页弄懂：读、看、动手、答题；卡住就问 | 几十分钟 |

所以设计的分量也该这样分配：**九成的心思给课时**，门厅只做两件事：一眼回到原处，一眼看清全局。

## 1. Apple 的新设计体系（HIG 与 WWDC25 两场讲座原文）

- **内容层与功能层分开。** 液态玻璃（Liquid Glass）是一层独立的功能层，用于控件和导航，浮在内容上方；内容从下面滚过去、透出来。*“Don't use Liquid Glass in the content layer”*，也不要玻璃叠玻璃，而且要少用。
  → Mathnim：图和正文是内容，铺满；导航、继续、问答入口这些控件浮在上方的一层。
- **层级来自版式和分组，不来自装饰。** 讲座原话：*hierarchy should be expressed through layout and grouping*。按钮的额外背景、边框都该清掉。
  → Mathnim：去掉卡片套卡片；用分组、对齐和留白表达关系。
- **同心。** 圆角和边距围绕同一个中心嵌套：内圆角 = 外圆角 − 内边距。有三种形状：固定圆角、胶囊、同心形。圆角太“掐”或太“张”都会破坏平衡。
  → Mathnim：定一套半径体系（窗口 28 → 卡片 20 → 图 12 → 胶囊），让嵌套关系一眼可读。
- **浮层从源头长出来。** 动作面板从被点的按钮里弹出，而不是永远从底部升起。
  → Mathnim：问答从被选中的那句话长出来；课时从课程页上它的缩略图展开（同一个几何体连续变化）。
- **静止时安静，触碰时亮起。** 元素平时不显眼，交互时才“抬进玻璃”。动效要有用、简短、可打断，不为动而动；要可以关掉。
- **滚动边缘效果不是装饰**：只在浮动控件和内容交界处用，用来澄清边界。
- **焦点随深度变化。** 打断主流程的任务用一层压暗把注意力集中起来；并行的任务只做轻微分隔，不打断。
- **连续性。** 手机是“拉近”的窄竖版，电脑是“展开”的宽画布；同一个结构，不同的展开程度。功能不随尺寸改变，只改变露出多少。
- **读写习惯**：重要的放在上方、起始侧；对齐表示同组，缩进表示从属；渐进披露，不一次摆出所有选择。

## 2. 设计理论

- **Dieter Rams**：好的设计尽可能少。诚实、不打扰、经久，细节一丝不苟。
  → 每个元素都要回答“它在为讲明白做什么”。
- **Tufte**：
  - 数据墨水比：墨水用在信息上，不用在框和底色上；
  - 分层与分隔：用浓淡和间距区分主次，不用框；
  - 小倍数：同一尺度下的一组小图，比一张大图说得多；
  - 微观/宏观阅读：远看是全局，近看是细节。
  → 课程的结构和进度可以“画出来”，但要画得有质感，而不是几根线。
- **格式塔**：接近、相似、连续、闭合、图底、共同区域。
  → 分组靠距离和共同区域，不靠线框。
- **Bret Victor**：可探索的解释；抽象阶梯（具体 ↔ 抽象来回走）；让读者“看到数据、看到比较”。
  → 这本来就是 Mathnim 课程的做法；界面也该让人在“整门课 ↔ 一课 ↔ 一页”之间平滑地升降。
- **排印**（Bringhurst、Tschichold、Müller-Brockmann）：
  - 正文行长约 45–75 个字符（中文约 30–40 字）；
  - 少用几个层级、拉大它们之间的差距；
  - 网格是秩序，不是牢笼；非对称版式更有张力。
- **原研哉（无印良品）**：“空”。空不是什么都没有，而是留给人去填。白是接收的能力。
  → 留白给学习者的思考，而不是给装饰。

## 3. 建筑师的灵感

- **Louis Kahn：服务空间与被服务空间。** 理查兹医学楼把楼梯、管道这些“服务空间”放进独立的塔，让实验室保持完整。
  → 课时页里，正文和图是被服务的房间；工具、进度、导师是服务空间，各有固定位置，不侵入房间。
- **Kahn：埃克塞特图书馆。** *“A man with a book goes to the light.”* 书库在里，读书的座位在外圈窗边；中央的大空间让人一进门就看见所有的书。
  → 首页像那个中庭：一进门就看见全部的课；你自己的位置（窗边的座位）在光最好的地方。
- **安藤忠雄：光与路径。** 进入之前先经过一段路，压低、转折，然后豁然开朗；空间的意义来自你走过它的顺序。
  → 首页 → 课程 → 课时是一段“入口过渡”：每一步尺度收拢、焦点变强，到课时只剩一件事。
- **柯布西耶：建筑漫步（promenade architecturale）和模度。** 建筑是被走过的，视线随路线展开；比例来自一套统一的尺度。
  → 课程的结构就是一条漫步路线；全站尺寸来自一套比例（8 的倍数与黄金分割的字号阶梯）。
- **SANAA：劳力士学习中心。** 一整片连续起伏的地面，没有走廊和隔墙，用地形和庭院区分区域，内外通透。
  → 课程不是一格格卡片，而是一片连续的地形；区域靠“地势”和留白分开。
- **苏州园林：框景、借景、移步换景。** 漏窗、月洞门把一处景框起来；每走一步，景就换一次。
  → 图是被“框”出来的景；一页一页地走，景一步一换：课时的节奏就是移步换景。
- **Peter Zumthor：氛围、材料的存在感、亲密的梯度。** 空间先被身体感觉到，再被理解。
  → 材料（纸、玻璃、墨）各有角色：纸承载内容，玻璃承载操作，墨承载结构。
- **Christopher Alexander：模式语言。** “两面采光的房间”“亲密梯度”“入口过渡”“窗边的位置”。
  → 公共的在外（全部课程），私密的在内（我的笔记、我的提问）。

## 4. 由此得出的约束（三版都遵守）

1. **两层**：内容层（图、正文，铺开）和功能层（导航、继续、提问，浮在上方，克制地用材质）。
2. **一屏一个焦点**；层级用版式、分组、尺度和留白表达，不靠框和底色。
3. **同心几何**：一套圆角与间距体系，嵌套关系可读。
4. **入口过渡**：首页 → 课程 → 课时，尺度递进收拢，焦点递进加强；转场保持几何连续（课时从它的缩略图展开）。
5. **图是主角**：用框景的方式呈现图；进度和结构用图形表达，但要有质感（图、材质、光），不是几根线。
6. **不俗**：材质、阴影、玻璃、渐变都可以用，但每一处都要有理由；不堆砌，不炫技，不用千篇一律的“AI 风”。
7. 一个浅色主题；没有说明性的界面文字；双语；手机上是同一结构“拉近”的版本。

## 5. 三个方向

| 方向 | 一句话 | 来自 |
|---|---|---|
| **展厅** | 每个想法是一处被框起来的景；课程是一次展览，课时是一个房间，你沿着展线移步换景 | Kahn 的图书馆与光、苏州园林的框景、美术馆的墙面文字 |
| **玻璃** | 内容铺满，操作浮在一层液态玻璃上；一切从源头长出、连续变形 | Apple 新设计体系：内容层与功能层、同心、连续 |
| **平面** | 整套课程画成一张建筑平面：单元是房间，课时的面积就是它的时长，你的路线穿过每一道门 | 柯布西耶的漫步路线、SANAA 的连续地形、Tufte 的信息设计 |
