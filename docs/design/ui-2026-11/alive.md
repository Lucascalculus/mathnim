# 像个人：Mathnim 怎样“有生命、有思考、有性格”（2026-11-03）

## 1. 这个目的到底想要什么

表面的要求是“像多邻国那样有角色互动”。往下挖三层：

1. **想要的结果**：学习者更愿意开口问。卡住时问一句，是 Mathnim 最值钱的一个动作，而现在页边那条手写线太安静，像一张表单。
2. **为什么会愿意**：人对“有人在”的东西会自然地开口，对工具不会。Reeves 与 Nass 的《媒体等同》、CASA 范式反复证明：只要几个最小的社会线索，人就会把电脑当成社会的另一方来对待。Mayer 的“社会主体”研究（personalization、voice、embodiment 三条原则，效应量 0.36–0.79）说的是同一件事：当学习者觉得对面是一个“人”，会更努力地去理解。
3. **“人”最少要有什么**：不是脸，也不是身体。心理学里有两个经典结论：
   - **Heider 与 Simmel（1944）**：两个三角形和一个圆在屏幕上移动，几乎所有观众都会讲出一个有意图、有情绪的故事。生命感来自**运动的方式**：自己发起、有目标、会犹豫、会回应别的东西（Scholl 与 Tremoulet 2000；Tremoulet 与 Feldman 2000：一个点只要不受外力地改变速度和方向，看起来就是活的）。
   - **共同注意**（Tomasello）：人类“教”这件事的最小单位，是两个人一起看同一个东西：你看哪里，它也看哪里；它指给你看，你就看过去。一个东西只要表现出“它在看你看的地方”，就开始像一个人。

所以，“像个人”要的不是一个吉祥物，而是三件事：

| 人的特征 | 在界面里是什么 | 为什么对“讲明白”有用 |
|---|---|---|
| **在场，在看你看的地方**（共同注意） | 它跟着你读到的那一段，看向你指着、选着、拖着的东西 | 你不用描述“我说的是哪句”，它已经在那儿了 |
| **看得见的思考** | 回答之前，先在你的文字下面划线、在图上圈出它在想的那一块，然后边想边写；在逗号和句号处会停顿 | 信号原则（d=0.46）与空间邻近（d=0.79）：它指给你看的，正是要看的地方 |
| **有记忆、有态度** | 记得你问过什么；会说“我第一次也选了这个”；会对一个想法表现出喜欢；不确定的时候直说 | 把犯错变成正常的事；关系是靠记忆建立的 |

## 2. 从多邻国学什么，不学什么

多邻国的角色之所以活，不是因为画得可爱，而是因为它们**会对你做出反应**，而且性格前后一致。我们学这两点。

不学的：
- 用愧疚驱动（哭泣的猫头鹰、断签提醒）；
- 分数、连胜、联赛（“游戏式奖励太土了”）；
- 卡通形象和机器人图像（TASTE §5）；
- 静止时也在动的循环动画（TASTE §6）。

## 3. 概念：一支有心思的笔

导师不画成人，而是**一支笔**：页边上的一个小笔尖，用墨色画，笔尖带一点课程色。它是 Mathnim 自己的东西：我们的身份本来就是“用运动讲明白”，这支笔就是“运动”本身变成了一个角色。像一本被学长认真批注过的旧课本，只是这位学长还在，会回你话。

它的行为规则（性格就是规则的总和）：

1. **安静地陪着**：你在读，它就待在页边、和你读的那一段同高，跟着你走，慢半拍（弹簧，不回弹）。你停下，它也停下。没有任何待机动画。
2. **看你看的地方**：鼠标指到一句话、你选中几个字、你拖动图里的东西，笔尖就转过去朝着那里，动作略晚、略软。
3. **只在你像是卡住时才开口**：在一段上停留很久、往回翻、反复拖同一个东西，它会在页边写一个很短的问题（就是它猜你想问的）。它从不弹窗，从不打断。
4. **思考看得见**：被问到时，它先移到你的文字旁划一道线，或者在图上圈一下，顿一顿，再回到页边开始写；需要时它会画一张小草图。写字的节奏像说话：逗号停一下，句号停久一点。
5. **说人话**：用“我”和“你”；短句；会说“诶”“其实”；会坦白“我第一次也以为……”；不确定就直说；从不空夸（不说“真棒”），只为一个想法高兴（“对，面积不一样，这就是全部秘密”）。
6. **记得你**：你问过的留在原处，用一条细线连到原句；下次在别处遇到同一个东西，它会提起上一次。
7. **知道退后**：动效减弱时，它只出现、不移动；你在做题时，它不说话，等你选完。

## 4. 每个地方的“生命”

- **首页**：它给你写一句话，不是欢迎语，而是你的近况：“上次停在‘总量相同，时机不同’。小车还停在墙后 7.5 厘米。”然后画一个箭头指向“继续”。课程旁边有它的批注，像朋友在你的课表上写的字。
- **课程页**：它在课程的平面图上做了批注：哪一课最难，哪一课它最喜欢，你在哪。
- **课时，阅读**：它跟着你读；你停住，它写下一个问题；你问，它划线、思考、写字，需要时画草图（比如“刹车的平均时刻”画成一根杠杆，支点就是 $t_c$）。
- **课时，演示**：它和你一起看图。旁白说到“灰色数字”时，它在图上把那一排数字圈起来。
- **课时，题目**：你选完之前它一个字都不说。选错了，它在你的选项旁写“我第一次也选了这个”，然后画出两条速度曲线，涂出它们下面的面积：面积就是走过的距离，两块不一样大。选对了，它只画一个勾。

## 5. 风险，以及怎么守住

- **诱人的细节**（Harp 与 Mayer 1998）：任何不指向概念的动作都是噪声。所以笔的每一个动作要么在陪你（跟随、看向），要么在指（划线、圈、画图）。
- **打扰**：它只在你停住时开口，而且只写在页边；正在读、正在做题的时候，它不出声。
- **装可爱**：性格来自判断和诚实，而不是表情和语气词堆砌。
- **“假装是人”**：它是一支笔，不冒充人；它的话由模型生成，页面上要诚实。
