同一套材料，三种组织方式

三个方向共用一套设计系统，各自把“图是展品、课是一段路、问过的留在原处”里的一件做到最强。数据是真实的课程、真实的图（从课的场景按 1920 × 1080 重新渲染）和 MPC 第 2 课的真实文字；学习进度是虚构的。理论和案例见 research.md。左下角的条可以在方向和页面之间切换。

三个方向共用
纸是方的，手是圆的

正文、图、图版用直角和十字裁切线；能按的东西浮在上面，用胶囊和同心圆角。方与圆的对比本身就分开了“内容”和“操作”，不用底色和边框。没有模糊玻璃。

图版是细节，不是缩略图

每课的图取颜色最集中的那一块（16:10），按原图三倍分辨率渲染，所以小卡片上也读得清；没有场景的课，用它的标题排成一块字版。

颜色分量相等，动效是弹簧

五门课的强调色在 OKLCH 里同一明度、相近彩度，只换色相。所有过渡用 Apple 的时长 / 回弹弹簧（换算成 CSS linear()）；步与步之间，向前从右进、向后从左进。

方向一

展厅

图是展品。首页是能一眼看见所有课的中庭，课程页是一次展览的平面，课时是一个房间：图在最亮处，说明挂在旁边，导师在页边。

来自：Kahn 的埃克塞特图书馆与金贝尔美术馆、斯卡帕的古堡博物馆、贝耶勒基金会、Ciechanowski 与 Distill

最强
图被认真安放：白色图版、一道光一样的阴影、一行说明；课程页顶部的“平面图”按时长画出每一课；课程页上的图版读得清。
风险
白盒子式的冷；课与课之间的叙事较弱；手机上整图偏小，需要点开放大。

方向二

路线

课是一段路。线长就是时长；课程页从“出发”一路走到“到达”，单元是街区，旁边跟着一张小地图；进了课时，同一条路继续成为步骤：过去的调暗，当下点亮，下一步露出一角。

来自：Beck 的地铁图（留下问题要的）、Lynch 的城市意象、Cullen 的序列视觉、留园的入口、萨尔克的那条线、Mela 的烹饪模式

最强
回答“我在哪、还有多少、下一步是什么”最清楚；课程页对 45 课的大课也成立；课时左边的步骤栏让人永远知道位置。
风险
线画多了就成了装饰；地铁图在课程网站上不少见，要靠“线长 = 时长”和两端撑住，而不是靠地铁的样子。

方向三

镜头

内容铺满，操作都在一只浮在下方的“手”里，它随页面变形：首页是继续，课程页是返回和继续，课时是步骤、播放、问和继续。问题从选中的句子里长出来，收起时折回成句末的编号；课时从课程页上它的那一格放大出来。

来自：Apple 新设计体系的两层结构与“从源头长出”、灵动岛、iA Writer 的专注、照片 App 的沉浸谱

最强
图最大、干扰最少；所有操作一个地方，手机上一只拇指够得着；提问最直接（选中即问）。可以试：在课时页选中一句话，点“问”；点手里的步骤条。
风险
很依赖动效和细节，做不好就是廉价的仿玻璃；首页的“全部课程”是一张张小图，信息气味弱于前两个方向。

建议

不选一个，按地方取最强的那一半

  1. 课程页用“路线”。从出发走到到达、线长等于时长、单元是街区、旁边一张随滚动的小地图：对 8 课和 45 课的课都成立，最能回答“我在哪、还有多少”。
  2. 图的安放用“展厅”。细节图版、白底加一道光的阴影、一行说明；课时里图得到最多的光，说明紧挨着它。
  3. 操作用“镜头”的一只手。手机上继续、问、步骤都在拇指下；场景里播放器进到手里，页面上只剩图和那句话。桌面上保留页边的“问”（展厅 / 路线的做法），因为大屏有地方让问题和正文同高。
  4. 首页用“展厅”的目录行加“路线”的线。每门课一行：图、名字、一句话，右边是它的进度和继续；线长等于时长，作为全部课程的总览。
  5. 课时的位置感用“路线”的步骤栏（桌面在左，手机收进手里），步与步之间按方向滑动。
还没做的

图是静态的截图：真正的课里它在动、能拖。手机上把图点开到全屏（沉浸的那一档）还没做。英文版没有排。

没有接入站点代码：这是放在 docs/design/ui-2026-11/ 的独立预览，用仓库根目录的静态服务器打开（.claude/launch.json 里的 design-preview）。
