# 通用积木：规划（2026-11-04）

积木是画数学用的名词：数轴、函数图像、平面、地形、分布、网络……每一门课都会用到，和具体哪门课无关。
它们和「动效」页的十个数学动画是两回事：动画是动词（涌现、展开、投影），积木是名词，可以拿在手里拖、放大、读数。
动画里已有的（等值线涌现、流线、橡皮膜网格、投影光束、积分堆积……）以后可以当积木的出场方式。

预览在 `docs/design/specimen/?v=blocks`，每块积木是一个模块 `gpu/blk/<名字>.js`，共用 `gpu/lib/plot.js`
（刻度、坐标、采样、玻璃手柄、标记）。每块都自带验收测试，由页面自己量。以后进引擎时，每块对应引擎里的「一种东西」，
数学部分和画法分开写，方便搬。

## 共同的样子（为什么是我们的，不是 Manim 的）

- **纸上的精密感**：坐标轴是石墨细线（脚手架），不画满格网格，只在主刻度交点放一个小点阵；刻度是 1-2-5 的整齐数，
  标签用等宽数字，小数位数恰好够用（不会出现 0.30000000000000004）。
- **颜色就是名词**：一条曲线、一块面积、一个向量各有自己的颜料；大面积只用淡色，细线和小记号用纯色。
- **空心是猜的、实心是真的；虚线是近似、实线是真值**：开区间的端点空心、闭区间实心；割线是虚线，h→0 时虚线合拢成切线。
- **玻璃珠是你的手**：凡是能拖的，都是同一颗玻璃珠。
- **石膏白模**：能摸的「东西」（地形、立体）是一块白色石膏模型，在唯一的相机和唯一的光下；转到正上方就是要读的图。
- **差值用石墨斜线**：误差、被减掉的部分画成斜线，不另起颜色。
- 图里只有标签，没有句子；静止时不动，碰到才回应；朱红只留给「下一步」按钮，积木里不用。

从 Manim 借的是好想法，不是样子：非线性变换前先把网格线细分（`prepare_for_nonlinear_transform`），
`get_secant_slope_group` 的斜率三角形，`get_riemann_rectangles`，`ValueTracker` / `always_redraw`（在这里是参数和派生值）。

## 全部积木

★ = 第一批，正在做。

### 量
1. ★ **数轴** 一个数是线上的一个位置；区间端点空心不含、实心含；放大时刻度一层层细分，标签的小数位跟着变。
2. **量尺与括号** 两个记号之间的长度、一段的名字（并进工具库）。

### 函数
3. ★ **函数图像** 每个点都是 (x, f(x))；任何地方都画得准，断开处就断开；玻璃珠沿曲线读数。
4. ★ **切线与斜率** 割线随 h→0 合拢成切线；底边为 1 的斜率三角形，高就是斜率。
5. ★ **面积与累积** 有正负的面积；下面那条曲线是累积量 A(x)，它在每一点的斜率等于 f(x)；黎曼和随 n 收敛。
6. **参数曲线** 一个点沿曲线走，速度是贴着它的箭头。

### 空间
7. ★ **平面与矩阵** 一个矩阵把整张平面一起变：网格仍平行等距，单位方块的面积变成 |det|，特征方向只伸缩不转。
8. **向量与张成** 首尾相接的加法、数乘、两个向量张成的线或面。
9. **投影与距离** 垂足、直角记号、残差；最近点就是垂足。
10. **几何构造** 点、线、圆、交点；拖动自由点，依赖它的一起动，不变量一直成立。
11. **三维坐标** 唯一相机下的点、向量、平面，沿轴拖动。

### 地形与场
12. ★ **等高线地图** 每条线高度相同；线密的地方陡；梯度垂直于等高线、指向上坡；计曲线上写高度（地形图的写法）。
13. ★ **石膏地形** 同一个函数做成石膏地形放在底座上；水面升到哪，岸线就是那条等高线；相机转到正上方，就是等高线地图。
14. **向量场** 间距均匀的流线，一颗探针读出那里的箭头和它的积分曲线。
15. **地形上的路径** 梯度下降、动量的轨迹画在等高线上：步长大了会来回跳。

### 随机与数据
16. **分布** 样本一粒粒落下，堆成直方图，收敛到密度曲线；均值和标准差标在轴上。
17. **散点与拟合** 最小二乘直线和残差；拖一个点，直线跟着重新拟合。
18. **概率是面积** 单位方块按 P(A)、P(B|A) 切开；重叠的半透明纸是「且」；贝叶斯就是面积之比。
19. **不确定的带** 很多条样本曲线淡成一条带。

### 结构
20. **网络** 节点和边，力导向排好后就静止；拖一个节点，边像线一样拉着别的节点；最短路径。
21. **树** 整齐的树形排版；收起、展开；同样的子树画得一模一样。
22. **矩阵格** 数值的热力格（单色的明度阶梯，有正负用两种颜料）；行乘列时，那一行和那一列亮起来。
23. **数组与滑动窗口** 一排格子、滑过的窗口、卷积的输出一格格出来。
24. **时序图** 几条生命线，消息箭头随时间往下走（网络协议、分布式系统）。

### 波与周期
25. **单位圆与波** 角度在圆上转，它的高度在右边展开成正弦；弧长就是弧度。
26. **叠加** 几个正弦加起来，项数越多越像目标；吉布斯现象。
27. **复平面** 乘一个复数就是转一下再伸缩；单位根。

### 时间
28. **时间曲线与相图** x(t)、v(t) 和相平面上的 (x, v) 是同一个状态；一颗珠子拖动时间。

## 第一批（2026-11-04 做完）

七块都过了自己的验收（页面自己量；无头 Chrome，WebGL 用软件渲染）：

| 积木 | 量出来的 |
|---|---|
| 数轴 | 200 种放大下 1979 个标签：重叠 0，不是整数倍 0，读回不符或多余的零 0；括号与端点一致 |
| 函数图像 | 四种函数、三种缩放：与真曲线最大偏差 0.200 px；跨过断点 0 段；跳跃端点 28/28 |
| 切线与斜率 | h 减半，误差之比 1.90–2.09（一阶）；h = 0 时与真切线相差 2e-13 px |
| 面积与累积 | A 与精确积分相差 6e-11；斜率与 f 相差 2e-8；n 从 16 到 32 误差之比 4.01 |
| 平面与矩阵 | 300 个矩阵：面积 = \|det\|（误差 4e-15）；Av = λv（3e-15）；椭圆半轴 = 奇异值 |
| 等高线地图 | 5368 个点离高度最多 0.0005；梯度与等高线离 90° 最多 0.09°；高度标注冲突 0 |
| 石膏地形 | 俯视时 100% 的等高线点落在岸线上；俯视画面横平竖直、3 : 2 |

在真实的鼠标事件下试过：点数轴端点（空心 ↔ 实心，括号跟着变）、拖 î（矩阵和 det 跟着变）、拖水位。
函数图像、切线、面积、等高线的拖动走同一个拖动工具，没有单独试；手机宽度没看。

## 顺序

第一批（★ 七块）先把底子打好：数轴、函数图像、切线、面积、平面、等高线、石膏地形。它们共用的东西（刻度、采样、
坐标、手柄、标记）在这一批里定型，后面的积木都建在上面。第二批：分布、散点与拟合、网络、矩阵格、单位圆与波、
概率面积。第三批：其余。
