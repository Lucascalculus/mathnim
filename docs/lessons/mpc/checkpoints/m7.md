## Design (lesson id `mpc-m7-disturbances`, file `m7_disturbances.ts`, mode 'essay')
Steps, in order:
1. **read 'why'.** The model is never exact, and three things go wrong:
   - a constant unknown push leaves an offset;
   - unmeasured or noisy states call for an estimator;
   - bounded, changing disturbances call for robust (tube) MPC.

   M1 showed that re-planning absorbs a one-off push. A steady push is different.
2. **scene 'offset-scene'**: `vis('mpc_offset', { story: 'offset' })`, narrated. The cart rests 10.8 cm short at q = 1, yet the dashed plan always expects to reach the flag: the model plans with no wind.
3. **derive 'offset'.** At rest v = 0 and the net acceleration is 0, so u = −d. Then u = −K_p e gives e = d/K_p. With q = 1: K_p = 2.79 and d = −0.3, so e = −10.8 cm. Note that MPC = LQR here, because the limits are inactive and P is the LQR P.
4. **checkpoint predict 'q-predict'.** "q 1 → 10: the offset?" The correct option is "shrinks to about 3.7 cm but stays" (K_p = 8). Misconception `q-removes-offset`.
5. **read 'fix-idea'.** If the model knew the wind, the target would shift: hold u_s = −d̂ at the flag, and e = (d − d̂)/K_p.
6. **explore 'offset-world'**: `attach('mpc_offset')`, action "New wind / 换一阵风" calling `scene.new_wind()`, cue order q, d̂, source.
   - Goal `by-hand`: estimate off and `at_flag()` (rest within 5 mm). This needs d̂ ≈ −0.30, which the learner can infer: the cart holds a push of +0.30, or d = K_p e.
   - Goal `estimated`: estimate on, `at_flag()`, and `wind_changes ≥ 1`.
   - Detector `just-raise-q` (misconception `q-removes-offset`): estimate off, |d̂| < 0.005 and q ≥ 5.
   - Detector `wrong-sign` (misconception `push-is-disturbance`): d̂·d < 0 and |d̂| ≥ 0.1, so the offset grows.
   - Detector `retune` (progress): the learner tunes by hand again after the wind changed.
   - solve: set dh = −0.3 and emit; then `new_wind()`, set est = 1 and emit.
   - Not met at entry: the offset is −10.8 cm and estimate is off.
7. **derive 'offset-free'.**
   - The augmented model: x⁺ = Ax + B(u + d), d⁺ = d.
   - The estimate: d̂⁺ = d̂ + λ (v_meas − v_pred)/Δt, with λ = 0.2, so error⁺ = (1 − λ) error.
   - Why this is integral action: d̂ is a running sum of prediction errors, so at steady state the error must be 0.
   - The steady target: [[I − A, −B], [C, 0]] [x_s; u_s] = [B d̂; r].
8. **read 'where-enters'.** The RMD Lemma 1.8 rank test, with only position measured:
   - B_d = B gives det = Δt² ≠ 0, so it works;
   - an output bias gives rank 2, so it fails. For an integrator, a sensor bias and a shifted resting position look identical (Qin & Badgwell).

   Teach that the disturbance must enter where the real one does.
9. **Kalman section.**
   - read: "predict with the model, correct with the measurement, weighted by trust";
   - a scene from a new `mpc_kalman` visual using `kalman_run()`:
     - the p plot shows the noisy y and the estimate;
     - the v plot shows differenced velocity (RMS about 0.8 m/s) against the filter (about 0.12);
     - a right panel shows the prediction and measurement bells and their product, L_p ≈ 0.29;
   - derive the predict/correct equations with W (process) and V (measurement). Do NOT call them Q and R. Cite Welch & Bishop.
10. **Tube section.**
    - read: the idea, citing Mayne et al. 2005 and RMD §3.5;
    - a scene from a new `mpc_tube` visual, using `tube_nominal`, `tube_follow`, `disturbance_history` and `tube_widths` (p 0.176, v 0.154, u 0.22 at w̄ = 0.15). It shows three things:
      - open loop: 4 of 12 runs cross the wall;
      - feedback: the runs stay within ±0.12 m but 8 of 12 cross;
      - wall tightened by 0.176: 0 cross;
    - the formulas e⁺ = A_K e + w and X̄ = X ⊖ S.
11. **Code step (optional)**: offset-free loop in numpy/cvxpy. Python with cvxpy 1.8.2 is available to test it.
12. **Checks**, all transfer:
    - number: a drone sag with d = −0.5 and K_p = 2.5 gives 20 cm;
    - choice: an output bias on the cart is not detectable;
    - choice: a noisier sensor means a larger V and a smaller L, so the estimate is smoother but slower;
    - text: offset-free vs tube.
13. **read 'in practice'** (summary).
