## 0. 本部分总览

### 0.1 四课的主线

- **D1** 定义信号：把"哪个更好"变成一个数（Bradley–Terry），并看清这个数在实践中从哪来、怎么验。
- **D2** 追这个信号：从零推出策略梯度，再到 PPO 的截断；然后给目标拴上 KL 缰绳，推出缰绳下的闭式最优解，并亲手看到奖励投机。
- **D3** 抄近路：把 D2 的闭式解反过来用，得到 DPO；再看它"只看差距"带来的似然位移。
- **D4** 落地：变体一张表带过，时间花在偏好数据怎么造，以及 SFT、DPO、RLVR 之间怎么选。

**贯穿四课的四根线**（制作时保证前后呼应，旁白里要点名回扣）：

1. **平移不变 → Z 消掉。** D1 证明 Bradley–Terry 只认同一个提示下的奖励差。D3 推导中的 β·log Z(x) 恰好是"只依赖提示的平移"，所以消掉。
2. **全胜者的奖励停不下来 → IPO。** D1 世界里，一个 3 战全胜的回答，最大似然下奖励发散。D3 的 DPO 同样会把差距推向无穷。D4 用 IPO 和标签平滑给出有限的目标差距。
3. **π\* ∝ π_ref·e^{r/β}。** D2 的缰绳世界精确计算它。D3 证明 DPO 训练出的策略也是同一种"倾斜"，倾斜方向由隐式奖励决定，所以概率会流向数据里从没出现过的回答（似然位移）。
4. **"指标在变好"≠"模型在变好"。** 依次是：D1 奖励模型的训练准确率，D2 代理奖励，D3 的 DPO 损失和偏好准确率，D4 评委胜率。每课都有一道对应的诊断题。

## D1 为什么要偏好，以及奖励模型

- **时长：** 约 29 分钟
- **前置：** B1（SFT 损失）、B3（损失低 ≠ 好）、A1 决策图
- **技能 id：**
  - `pref-signal`：偏好信号能表达什么
  - `bradley-terry`
  - `rm-train`
  - `rm-validate`
  - `reward-sources`
- **误区 id：**
  - `sft-says-better`：多给些好例子做 SFT，就能表达"哪个更好"
  - `absolute-scores`：让人直接打 1–10 分更准
  - `reward-has-units`：奖励的绝对值有含义（"3.2 分算好"）
  - `rm-train-acc`：训练集准确率高，奖励模型就能用
  - `rm-is-truth`：奖励模型的分数就是人类偏好本身
  - `judge-unbiased`：大模型评委没有系统偏差

### 学完能做到

1. 举出 SFT 数据表达不了、而偏好数据能表达的两类信号：负例，以及两个都可接受的回答之间的相对好坏。能说明"判断比示范容易"是什么意思。
2. 从 Bradley–Terry 假设推出 P(y_w ≻ y_l) = σ(r_w − r_l) 和对应的损失；给出奖励差能算胜率，例如奖励差 2 对应约 88%。
3. 预测两件事：所有奖励加同一个常数，什么都不变；某个回答在数据里全胜，最大似然下它的奖励没有有限值。
4. 为奖励模型写一份验证清单：留出集准确率要和标注者之间的一致率比，长度受控的切片准确率，校准。能从一组指标里认出长度偏差。
5. 对给定任务，在四种奖励信号来源之间做选择，并说出各自的主要风险：BT 奖励模型、规则验证器、评分细则加大模型评委、两两比较的 AI 反馈。

### 要解开的误解

| 误区 | 证据 | 出处 |
|---|---|---|
| `sft-says-better` | SFT 只提高示范回答的似然：没有负例，也没法说"两个都行，但这个更好"。InstructGPT 里 1.3B 的 PPO 模型在人工评估中胜过 175B 的 GPT-3，同规模下 PPO 模型也胜过 SFT 模型 | InstructGPT 2203.02155〔标准〕；CS224N 用"语言建模 ≠ 帮助用户"引出偏好 [RP§1–2] |
| `absolute-scores` | 绝对打分噪声大，每个人的尺度不一致；两两比较更稳定 | [RP§2 Reward models] |
| `reward-has-units` | BT 只用到奖励差 | [RT§5]；README §4 已把它定为"图加题" |
| `rm-train-acc` | "先确认你的奖励模型是对的"，要看留出集准确率。只用长度当奖励，就能复现基于人类反馈的强化学习（RLHF）的大部分收益 | CS224N [RP§2]；Singhal et al. 2310.03716 [RT§5] |
| `rm-is-truth` | 代理奖励一路上升，真实质量却先升后降 | Gao et al. 2210.10760 [RT§5]，D2 展开 |
| `judge-unbiased` | 大模型评委有位置偏差、冗长偏差和自我偏好 | Zheng et al. 2306.05685〔标准〕 |

### 交互规格：`bradley_terry_fit`（world）

- **变量：**
  - r_B、r_C、r_D：可拖动的奖励柱。r_A 固定为 0，理由是第 6 段的平移不变，界面上写明"只有差值有意义，所以把 A 钉在 0"。
  - 开关"给 D 加一场负局"：D 对 C 的战绩从 3–0 变成 3–1。
  - 按钮"自动拟合"：做梯度上升，学习率 0.05，并配一个拟合步数的拖动条（0 到 10 万步，对数刻度）。
- **画面：**
  - 左边：四根奖励柱。

  1. 拖动 r_B 和 r_C，让三场对局的预测胜率都和观测胜率相差不超过 3 个百分点。
  2. 按"自动拟合"，拖动步数条，观察 r_D。
  3. 打开"给 D 加一场负局"。
- **应该注意到的（数值已用脚本验证）：**
  - A、B、C 的最大似然解是 r_B ≈ −0.89，r_C ≈ −1.33。此时预测胜率为 0.709、0.609、0.791，与观测值相差都在 1% 以内。
  - r_D 在第 100 步约 1.5，第 1000 步约 3.7，第 1 万步约 6.0，第 10 万步约 8.3，永远停不下来；与此同时，D 那一场的损失趋近于 0。
  - 加上一场负局后，r_D 收敛到 r_C + ln 3 ≈ −0.23，**低于 A**。只多一场比赛，D 就从"最强"变成了"不如 A"。
  - 奖励是互相牵连的：动 r_C，三场对局的预测胜率会一起变。
- **结束时的问题：** "r_D 为什么停不下来？真实的奖励模型靠什么避免这种情况？"
  - 答：数据完全可分。−log σ(Δ) 对任何有限的 Δ 都大于 0，而且随 Δ 增大一直下降，所以最优值不存在。
  - 实际的缓解办法：神经网络在样本之间共享参数，能泛化；只训练 1 轮或提前停止；正则化；增加比较。
  - 引出 D4：IPO 和标签平滑给出有限的目标差距。
- **标注：** 精确计算（BT 似然及其梯度上升）；战绩是虚构的玩具数据。
- **零件名：** `bradley_terry_fit`
- **goals：**
  - `match3`：三场对局的误差都小于 0.03；
  - `diverge`：拟合步数 ≥ 1 万，且 r_D > 5；
  - `one-loss`：开关打开后，r_D < r_A。
- **detectors：**
  - 学生把 r_B 拖到 r_A 之上（而观测是 A 7–3 胜 B）→ progress 提示"A 赢了 7 场，A 应该更高"；
  - 第 7 段选了"停在 A 附近"→ 本世界的 `diverge` 目标完成时，旁白回扣这个选择。
- **如何满足三条：**
  1. **关系：** 改一个奖励，三个预测胜率一起变；全胜导致发散；一场负局就让排名翻转。这些都是公式本身不显示、学生很难想象的。
  2. **形式对应：** 拖动柱子就是给回答打分；加一场负局就是加一条数据。
  3. **以问题收尾：** 第 7 段先下注，世界结束时回答"为什么停不下来"。

### 推导全文：Bradley–Terry（derive，第 5 段）

记号：同一个提示 x 下有两个回答 y_1、y_2，每个回答有一个看不见的"强度" s(y) > 0。

**第 1 步** $$P(y_1 \succ y_2 \mid x) = \frac{s(y_1)}{s(y_1) + s(y_2)}$$
*为什么：* 这是 Bradley–Terry（1952）的假设，也是最简单的、只依赖两者强度的模型：好比每个回答手里有 s 张彩票，从两人的彩票里抽一张，抽中谁谁赢。

**第 2 步** 令 $s(y) = e^{r(y)}$，其中 $r \in \mathbb{R}$：$$P = \frac{e^{r_1}}{e^{r_1} + e^{r_2}}$$
*为什么：* 网络输出的是任意实数，用指数保证强度为正。这就是两个选项上的 softmax。

**第 3 步** 分子分母同除以 $e^{r_1}$：$$P = \frac{1}{1 + e^{-(r_1 - r_2)}} = \sigma(r_1 - r_2)$$
*为什么：* 只剩下差值。所以对同一提示下的所有回答都加同一个常数 c(x)，概率不变（第 6 段的图；D3 里 Z 能消掉正是因为这一点）。尺度也随之固定：差 1 对应 73%，差 2 对应 88%。

**（可折叠）另一条路：带噪声的效用。** 设 $u(y) = r(y) + \varepsilon$，ε 独立同分布于 Gumbel 分布。两个 Gumbel 变量之差服从 logistic 分布，所以 $P(u_1 > u_2) = \sigma(r_1 - r_2)$。
*为什么讲它：* 它说明 σ 不是随手挑的，而是"标注者有噪声"的一种具体假设。如果把噪声换成高斯分布，得到的就是 Thurstone 模型（probit）。

**第 4 步** 数据 $\mathcal D = \{(x, y_w, y_l)\}$，用奖励模型 $r_\phi$ 求最大似然，等价于最小化
$$\mathcal L(\phi) = -\mathbb E_{\mathcal D}\big[\log \sigma\big(r_\phi(x, y_w) - r_\phi(x, y_l)\big)\big]$$
*为什么：* 似然是各条数据的 σ(Δ) 之积，取负对数就变成求和。这其实是一个二分类交叉熵，标签恒为"y_w 赢"，logit 是 Δ。换句话说，就是在差值上做逻辑回归。

**第 5 步** 记 Δ = r_w − r_l，则 $\frac{d}{d\Delta}\log\sigma(\Delta) = 1 - \sigma(\Delta) = \sigma(-\Delta)$，所以
$$\nabla_\phi \mathcal L = -\,\mathbb E\big[\sigma(-\Delta)\,(\nabla_\phi r_w - \nabla_\phi r_l)\big]$$
*为什么：* σ' = σ(1 − σ)。读法是：已经排对、而且差距大的对，权重 σ(−Δ) ≈ 0；排错的对，权重接近 1。D3 里 DPO 的梯度会出现**完全相同**的权重。

**第 6 步** 如果某个回答在数据里从没输过（它参与的每一场都赢了），那么把它的奖励继续调高，它参与的每一项 $-\log\sigma(\Delta)$ 都会继续下降，趋近 0 却永远取不到：**不存在有限的最优解**。
*为什么：* 这和逻辑回归在线性可分数据上的权重发散是同一个现象。见世界 `bradley_terry_fit`，D4 的 IPO 回扣这一点。

**填空（推导页最后一步）：** $P(y_1 \succ y_2) = \sigma(\;\_\_\_\_\;)$，答案是 $r_1 - r_2$。错答 $r_1 / r_2$ 标记误区 `reward-has-units`。

C-D1-1 的核心代码（代码页左栏，右栏按行讲解）：

```python
class RewardModel(nn.Module):
    def __init__(self, backbone):                       # 不带 LM 头的 AutoModel
        super().__init__()
        self.backbone = backbone
        self.head = nn.Linear(backbone.config.hidden_size, 1)

    def forward(self, ids, mask):                       # ids, mask: [2B, T]（右侧补 pad）
        h = self.backbone(input_ids=ids, attention_mask=mask).last_hidden_state  # [2B, T, H]
        last = mask.sum(-1) - 1                         # [2B]  最后一个真实 token 的位置
        return self.head(h[torch.arange(h.size(0)), last]).squeeze(-1)           # [2B]

def bt_loss(rm, chosen_ids, chosen_mask, rejected_ids, rejected_mask):
    # chosen 与 rejected 先补齐到同一长度 T，再拼成一个 batch，只做一次前向
    r = rm(torch.cat([chosen_ids, rejected_ids]), torch.cat([chosen_mask, rejected_mask]))
    r_w, r_l = r.chunk(2)                               # 各 [B]
    loss = -F.logsigmoid(r_w - r_l).mean()              # 第 4 步的损失
    acc = (r_w > r_l).float().mean()                    # 成对准确率
    return loss, acc
```

讲解要点：
- 为什么取最后一个 token：在因果注意力下，只有它看过整段回答。
- `logsigmoid` 比 `log(sigmoid(...))` 数值稳定。
- 骨干网络通常从 SFT 模型初始化〔标准，InstructGPT〕。

### 检验题

1. **计算**（number）：奖励模型给 A 打 1.5，给 B 打 −0.5。标注者选 A 的概率是多少？
   - 答案：σ(2) ≈ 0.88（容差 0.01）。
   - 错答 0.75（把分数当强度直接相除，1.5/(1.5+0.5)），标记 `reward-has-units`，反馈："只有差值有意义，差 2 → σ(2)。"
2. **预测**（choice，配图 F-D1-2）：所有回答的奖励都加 10，下列哪项会变？
   - 选项：①所有胜率；②奖励模型的损失；③都不变 ✓；④原本领先的回答，胜率会更高。
   - ①④标记 `reward-has-units`。
3. **诊断**（choice，再加一句解释，由 AI 判读）：一个奖励模型的指标如下——训练集准确率 0.94；留出集 0.71；标注者之间的一致率 0.73；在"被选回答更短"的那些对上 0.41；在"被选回答更长"的那些对上 0.86。最该担心什么？下一步做什么？
   - 答案：长度偏差。在人类偏好较短回答的那些对上，它低于随机水平，说明它在用"长"当捷径。整体 0.71 接近一致率 0.73，看上去正常，但把问题掩盖了。
   - 下一步：补充"短的赢"的对，或者按长度做配平；报告长度受控的准确率；在修好之前不要拿它去做 RL。
   - 判分要点：必须指出 0.41 < 0.5 这个切片是关键证据。只说"训练集和留出集差距大，过拟合了"只给部分分（`rm-train-acc`）。
4. **选择**（为每个任务选一项，再写一句理由）：
   - (a) 数学应用题的最终答案 → 规则验证器；
   - (b) 客服回复，要求遵守退款政策、语气得体 → 评分细则加大模型评委，用人工标注校准；
   - (c) 小说开头"哪个更吸引人" → 两两比较（人工或 AI），用来训练 BT 奖励模型或直接做 DPO。
   - 判分要点：(a) 选了奖励模型要扣分，因为有能判对错的程序就不该训练一个可以被钻空子的模型；(b) 必须提到用人工校准评委；(c) 必须是比较而不是打分。
5. **解释**（由 AI 判读）：用一句话说明，为什么偏好标注常问"哪个更好"，而不是"打几分"。
   - 要点：绝对分数有噪声、各人的尺度不一致；比较更一致；BT 只需要差值。

**本课的定位（依据 [RA§9]）：** PPO（近端策略优化，proximal policy optimization）加价值模型的做法今天已经很少用：TRL 上 894 个 PPO 模型，对比 14,257 个 GRPO 模型，也没有托管服务提供 PPO。本课仍然完整推导策略梯度、基线和截断，因为 E1 的 GRPO 直接建立在这三样东西上。PPO 在这里是一座"概念桥梁"；价值模型和 GAE 折叠为选读。KL 缰绳和奖励投机是所有"用学到的奖励做优化"的方法共同的问题，包括 DPO，所以讲足。

### 学完能做到

1. 用对数导数技巧推出 ∇J = E[R·∇log π]，说明为什么 R 不需要可微，并指出 REINFORCE 就是"在自己的样本上、按奖励加权的 SFT"。
2. 证明减去基线不改变期望梯度；在给定的小例子上算出有基线和没有基线时的方差。
3. 给定 (ρ, A, ε)，判断 PPO 截断后的梯度是推高、压低还是为 0，并解释为什么"纠错"不会被截断。
4. 推出 KL 正则目标的闭式最优解 π\* = π_ref·e^{r/β}/Z，并预测三种情况：β → 0、β → ∞，以及 π_ref(y) = 0。
5. 从"代理奖励升、真实质量降"的曲线诊断奖励投机，提出至少三种对策；估算 PPO 四个模型的显存。

### 要解开的误解

| 误区 | 证据 | 出处 |
|---|---|---|
| `pg-needs-diff-reward` | 策略梯度只对 log π 求导，奖励可以是程序、评委，甚至是人 | 推导第 2 步；CS224N "we reinforce good actions" [RP§2] |
| `pg-loss-meaningful` | 策略梯度的损失依赖于这一批采样，它的数值没有意义，应该看奖励 | CS336 作业说明（镜像来源）[RP§3.2] |
| `baseline-changes-objective` | E[b·∇log π] = 0，期望梯度不变 | 推导；`pg_baseline` 中的均值读数始终不变 |
| `clip-misread` | 截断只挡住"顺着优势方向继续走"，不挡纠错 | 分情况分析；`ppo_clip` |
| `kl-optional` | 奖励模型只在它的训练分布附近可信；真实质量随 KL 先升后降 | Gao et al. 2210.10760 [RT§5]；Lambert 第 15 章 [RP§2] |
| `reward-up-means-better` | 代理奖励一直在涨，真实质量先升后降 | 同上；`kl_leash_policy` |
| `negative-kl-bug` | 用 top-k、top-p 或改了温度采样时，样本并不来自 π 本身，k1 估计的平均值就可能为负 | HF 论坛 [RP§3.7] |

**过度优化的对策**（第 15 段列出，并标出处）：
- 用独立的真实评估（人工评估，或者更强、和训练用的奖励无关的评委）决定在哪停；
- 加大 β；
- 更大或更好的奖励模型（Gao：奖励模型越大，越不容易被过度优化〔标准〕）；
- 多个奖励模型集成或权重平均（WARM，Gemma 3 在用 [RA§6]）；
- 用当前策略的新样本重新标注、更新奖励模型；
- 长度惩罚，或者对奖励做长度校正；
- 对奖励做截断或归一化。

**第 16 段的公式卡：**
- 序列 KL：$\mathrm{KL}(\pi\|\pi_{ref}) = \mathbb E_{y\sim\pi}\big[\log\tfrac{\pi(y|x)}{\pi_{ref}(y|x)}\big] = \mathbb E_{y\sim\pi}\big[\sum_t \log\tfrac{\pi(y_t|s_t)}{\pi_{ref}(y_t|s_t)}\big]$。所以对一条从 π 采出的回答，各 token 对数比之和就是 KL 的单样本无偏估计（k1）。单个样本的值可以为负，只有平均值才保证 ≥ 0。
- 如果回答其实是从另一个分布 q 采出的（用了 top-k、top-p 或改了温度），$\mathbb E_q[\log\pi/\pi_{ref}]$ 就不再是 KL，可以为负：这就是 KL 读数为负的来历 [RP§3.7]。
- k3 估计量：每个 token 上取 $\tfrac{\pi_{ref}}{\pi} - \log\tfrac{\pi_{ref}}{\pi} - 1 \ge 0$，同样无偏（Schulman 2020 的博客〔标准〕）；E1 的 GRPO 把它加进损失 [RT§6]。
- 自适应 β：按目标 KL 自动调大或调小 β（Ziegler 1909.08593〔标准〕）。

### 推导全文

#### ① 策略梯度（derive，第 3 段）

记号：固定一个提示 x（对 x 再取期望即可）；回答 y ~ π_θ(·|x)；奖励 R(y) 可以来自奖励模型、评委或程序。

**第 1 步** $$J(\theta) = \mathbb E_{y\sim\pi_\theta}[R(y)] = \sum_y \pi_\theta(y)\,R(y)$$
*为什么：* 这是期望的定义。求和遍历所有可能的回答，项数是天文数字，但我们不会真去枚举它。

**第 2 步** $$\nabla_\theta J = \sum_y R(y)\,\nabla_\theta \pi_\theta(y)$$
*为什么：* R 不依赖 θ（奖励模型是冻结的，或者根本就是一段程序），梯度只经过概率。**我们从来没有对 R 求导**，所以 R 可以不可微。

**第 3 步** $$\nabla_\theta \pi_\theta(y) = \pi_\theta(y)\,\nabla_\theta \log \pi_\theta(y)$$
*为什么：* 这就是对数导数技巧，链式法则 ∇log π = ∇π/π 移项即得。

**第 4 步** $$\nabla_\theta J = \sum_y \pi_\theta(y)\,R(y)\,\nabla_\theta\log\pi_\theta(y) = \mathbb E_{y\sim\pi_\theta}\big[R(y)\,\nabla_\theta\log\pi_\theta(y)\big]$$
*为什么：* 式子里又出现了一个 π_θ(y)，所以它重新变回"在策略下取期望"，可以用采样来估计。

**第 5 步** $$\hat g = \frac1N\sum_{i=1}^N R(y_i)\,\nabla_\theta\log\pi_\theta(y_i),\qquad y_i\sim\pi_\theta$$
*为什么：* 用样本均值估计期望，这个估计是无偏的。这就是 REINFORCE（Williams 1992〔标准〕）。

**第 6 步** $$\log\pi_\theta(y\mid x) = \sum_t \log\pi_\theta(y_t\mid x, y_{<t})\ \Rightarrow\ \hat g = \nabla_\theta\Big[\frac1N\sum_i R(y_i)\sum_t \log\pi_\theta(y_{i,t}\mid x, y_{i,<t})\Big]$$
*为什么：* 自回归分解。方括号里的东西，正是"在自己采样出的回答上做 SFT"的对数似然，只是每条回答乘上了它的奖励。**REINFORCE = 在自己的样本上、按奖励加权的 SFT。**

**填空：** $\nabla J = \mathbb E[\,R(y)\cdot\_\_\_\_\,]$，答案是 $\nabla_\theta\log\pi_\theta(y)$。

#### ② 基线与优势（derive，第 6 段）

**第 1 步** 对任何不依赖 y 的 b：$$\mathbb E_{y\sim\pi}\big[b\,\nabla\log\pi(y)\big] = b\sum_y \nabla\pi(y) = b\,\nabla\sum_y\pi(y) = b\,\nabla 1 = 0$$
*为什么：* 先用第 3 步把 π·∇log π 换回 ∇π；概率之和恒为 1，与 θ 无关。

**第 2 步** $$\nabla J = \mathbb E\big[(R(y) - b)\,\nabla\log\pi(y)\big]$$
*为什么：* 减去一个期望为 0 的项，期望不变。但方差变了：方差里有 E[(R−b)²‖∇log π‖²] 这一项，它依赖 b。

**第 3 步（直觉）** 奖励全为正、又不减基线时，每个被采到的回答都会被往上推，信号只藏在"推多推少"里，要靠大量样本互相抵消。减去平均奖励之后，比平均好的被推高，比平均差的被压低。

**第 4 步（折叠：最优基线）** 把 θ 当作一维时，使方差最小的是 $b^* = \mathbb E[R\,\|g\|^2]/\mathbb E[\|g\|^2]$，其中 g = ∇log π。如果各个回答的 ‖g‖ 差不多，b\* ≈ E[R]。`pg_baseline` 的均匀策略下，b\* 恰好等于平均奖励。

**第 5 步** 优势：$A(x,y) = R(x,y) - b(x)$。b 可以依赖提示 x，但不能依赖 y。b(x) 有三种来源：
- 学一个价值模型 V(x)，这是 PPO 和 actor-critic 的做法；
- 用同一提示下其他样本的平均：RLOO 用"留一"平均〔标准，2402.14740〕，GRPO 用组内均值再除以标准差（E1）[RT§6]；
- 奖励的滑动平均。

**第 6 步（折叠：PPO 的逐 token 优势）** $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$，$\hat A_t = \sum_{l\ge0}(\gamma\lambda)^l\,\delta_{t+l}$（GAE，1506.02438〔标准〕）；大模型里常取 γ = 1〔标准〕。
*为什么折叠：* 这正是后来被去掉的那一部分 [RA§9]。

#### ③ 重要性比率与截断（derive，第 9 段）

**第 1 步** 生成回答是最贵的一环，所以希望一批样本能用来更新好几步。可是更新一步之后，样本就来自旧策略 π_old，而不是当前的 π_θ 了。

**第 2 步** $$\mathbb E_{y\sim\pi_\theta}[f(y)] = \mathbb E_{y\sim\pi_{old}}\Big[\frac{\pi_\theta(y)}{\pi_{old}(y)}\,f(y)\Big]$$
*为什么：* 这是重要性采样，Σπ_θ·f = Σπ_old·(π_θ/π_old)·f，要求 π_old 在 π_θ 有概率的地方也有概率。

**第 3 步** 代理目标 $L(\theta) = \mathbb E_{\pi_{old}}[\rho_\theta\,\hat A]$，其中 $\rho_\theta = \pi_\theta/\pi_{old}$。由 $\nabla\rho = \rho\,\nabla\log\pi_\theta$，在 θ = θ_old 处 ρ = 1，所以 $\nabla L = \mathbb E_{\pi_{old}}[\hat A\,\nabla\log\pi_\theta]$，正好就是策略梯度。
*为什么：* 代理目标在出发点上与真目标的梯度一致，是一个局部替身。（严格地说，这里忽略了状态分布的变化，是 TRPO 一系列工作里的近似〔标准〕。）

**第 4 步** 离 θ_old 远了，替身就不可靠：Â 是在旧策略下估计的，ρ 也可能很大，方差爆炸。TRPO 的办法是约束 KL(π_old‖π_θ) ≤ δ（1502.05477〔标准〕）；PPO 换成截断（1707.06347〔标准〕）：
$$L^{CLIP} = \mathbb E\big[\min\big(\rho\hat A,\ \mathrm{clip}(\rho, 1-\varepsilon, 1+\varepsilon)\,\hat A\big)\big],\quad \varepsilon = 0.2\ \text{[RT§5]}$$

**第 5 步（分情况）**

| | ρ < 1−ε | 1−ε ≤ ρ ≤ 1+ε | ρ > 1+ε |
|---|---|---|---|
| A > 0 | 取 ρA，梯度推高（纠错） | ρA，推高 | (1+ε)A 是常数，梯度为 0（够了，别再推） |
| A < 0 | (1−ε)A 是常数，梯度为 0（够了，别再压） | ρA，压低 | 取 ρA，梯度压低（纠错） |

*为什么：* min 取的是悲观的那一项。在"顺着优势方向已经走过头"的一侧，截断项更小，于是被取中，梯度为 0；在"走反了"的一侧，未截断项更小，梯度保留。

**第 6 步** 在大模型里，以上都按 token 计算：$\rho_t = \pi_\theta(y_t|s_t)/\pi_{old}(y_t|s_t)$，Â_t 来自 GAE，再加上价值模型的回归损失〔标准〕。E1 的 GRPO 保留了 ρ 和截断，但把 Â_t 换成组内归一化的奖励 [RT§6]。

#### ④ KL 正则目标的闭式最优解（derive，第 12 段）

目标：对固定的 x，在所有分布 π(·|x) 中求
$$\max_\pi\ \mathbb E_{y\sim\pi}[r(y)] - \beta\,\mathrm{KL}\big(\pi\,\|\,\pi_{ref}\big)$$

**第 1 步** $$= \sum_y \pi(y)\,r(y) - \beta\sum_y \pi(y)\log\frac{\pi(y)}{\pi_{ref}(y)}$$
*为什么：* 把期望和 KL 都按定义写成求和。

**第 2 步** $$= -\beta\sum_y \pi(y)\Big[\log\frac{\pi(y)}{\pi_{ref}(y)} - \frac{r(y)}{\beta}\Big]$$
*为什么：* 提出公因子 −β，两项合并到同一个求和里。

**第 3 步** $$= -\beta\sum_y \pi(y)\log\frac{\pi(y)}{\pi_{ref}(y)\,e^{r(y)/\beta}}$$
*为什么：* r/β = log e^{r/β}，两个对数合成一个。

**第 4 步** 定义 $$Z = \sum_y \pi_{ref}(y)\,e^{r(y)/\beta},\qquad \pi^*(y) = \frac{\pi_{ref}(y)\,e^{r(y)/\beta}}{Z}$$
*为什么：* 分母 π_ref·e^{r/β} 非负但加起来不等于 1；除以它的总和 Z，就得到一个真正的概率分布 π\*。于是 π_ref·e^{r/β} = Z·π\*。

**第 5 步** $$= -\beta\sum_y \pi(y)\log\frac{\pi(y)}{\pi^*(y)} + \beta\log Z\sum_y\pi(y) = -\beta\,\mathrm{KL}(\pi\,\|\,\pi^*) + \beta\log Z$$
*为什么：* 把 log(Z·π\*) 拆成两项；Σπ = 1。

**第 6 步** Z 与 π 无关；KL ≥ 0，当且仅当 π = π\* 时取等（Gibbs 不等式）。所以唯一的最优解是
$$\boxed{\pi^*(y\mid x) = \frac{1}{Z(x)}\,\pi_{ref}(y\mid x)\,e^{r(x,y)/\beta}}$$
最优值为 β·log Z(x)。

**第 7 步（性质，都在 `kl_leash_policy` 里看得到）**
- β → ∞：π\* → π_ref。
- β → 0：π\* 集中到 π_ref > 0 的回答里奖励最高的那个（若有并列，在它们之间按 π_ref 分配）。
- π_ref(y) = 0 ⇒ 对任何 β 都有 π\*(y) = 0，这是"墙"。
- $\frac{d\,\mathbb E_{\pi^*}[r]}{d(1/\beta)} = \mathrm{Var}_{\pi^*}(r) \ge 0$，所以缰绳越松，代理奖励越高，单调上升；真实质量却没有这个保证。

**第 8 步** 为什么不直接把 π\* 算出来：Z 要对所有回答求和。词表 128,256 [RT§3]、长度 100 的回答有 128256^100 ≈ 10^511 种。所以 RL 只能靠采样去逼近 π\*；D3 会找到绕开 Z 的办法。

**（折叠）另外两种看法：**
- 拉格朗日乘子法：对 π(y) 求导，得 r − β(log(π/π_ref) + 1) + λ = 0，同样得到这个形式。
- 贝叶斯后验：先验是 π_ref，似然是 e^{r/β}（Korbak et al. 2205.11275 [RT§5]）。

**填空：** $\pi^*(y) = \pi_{ref}(y)\cdot\_\_\_\_\,/Z$，答案是 $e^{r(y)/\beta}$。错答 $e^{\beta r}$ 的反馈："β 越大缰绳越紧，所以 β 在分母上。"

C-D2-1：

```python
rewards = torch.tensor([9.0, 9.5, 10.0, 10.5, 11.0, 12.0])  # 全是正的
logits = torch.zeros(6, requires_grad=True)                  # 策略参数
opt = torch.optim.SGD([logits], lr=0.05)

def pg_step(n=16, use_baseline=True):
    probs = F.softmax(logits, -1)
    y = torch.multinomial(probs, n, replacement=True)        # 采 n 个回答
    R = rewards[y]
    A = R - R.mean() if use_baseline else R                  # 优势
    logp = F.log_softmax(logits, -1)[y]                      # log π(y)
    loss = -(A.detach() * logp).mean()                       # REINFORCE
    opt.zero_grad(); loss.backward(); opt.step()
    return R.mean().item()                                   # 要看的是奖励，不是 loss
```

讲解要点：
- `detach()`：优势是常数，不参与求导。
- 最后一行注释呼应误区 `pg-loss-meaningful`。
- 把 `use_baseline` 关掉再跑一次，奖励曲线明显更抖。这一条也写进 L4 的预测清单。

   - (a) 不用基线时，单样本梯度估计只有两种取值（5.5 和 −5），它的方差是多少？答案 27.56（相对容差 2%）。

2. **预测**（choice）：A < 0，ρ = 0.7，ε = 0.2。梯度会怎样？
   - 选项：①为 0 ✓；②继续压低（`clip-misread`）；③推高。
   - 反馈：ρ 已经比 1−ε 还低，坏 token 被压够了。
3. **诊断**（choice，再加一句解释）：RLHF 训练到第 6k 步，代理奖励一直在涨；KL 从 2 涨到 15 nats；对 SFT 模型的人工胜率在 2k 步时是 58%，6k 步时是 47%；回答长了一倍，开头常是"好问题！"。

5. **解释**（由 AI 判读）：用一句话说明，为什么 REINFORCE 不需要奖励可微。

## D3 DPO：推导与几何

- **时长：** 约 32 分钟
- **前置：** D1（BT、平移不变）、D2（闭式最优解 π\*、`kl_leash_policy`）
- **技能 id：**
  - `dpo-derive`
  - `dpo-gradient`
  - `beta-ref-role`
  - `likelihood-displacement`
  - `dpo-practice`
- **误区 id：**
  - `dpo-no-kl`：DPO 没有奖励模型，所以也没有 KL 约束、不需要参考模型
  - `dpo-raises-chosen`：DPO 一定会提高被选回答的概率
  - `dpo-metrics-good`：DPO 的损失在降、偏好准确率在升，生成质量就在变好
  - `ref-irrelevant`：参考模型随便选哪个都行
  - `beta-comparable`：不同配方里的 β 数值可以直接比较
  - `dpo-equals-ppo`：DPO 和 PPO 在实践中完全等价

**本课的定位（依据 [RA§5]）：** DPO 仍是核心。OpenAI、Vertex、Azure 和 Together 都提供 DPO，Hub 上带 `dpo` 标签的模型有 13,519 个。但它在前沿配方里正在淡出：Llama 4 只在最后做"轻量 DPO"，OLMo 3 用 delta learning 构造的偏好对做 DPO。课尾用一张配方时间线交代这一点。

### 学完能做到

1. 从 D2 的 π\* 出发，独立推导出 DPO 损失，并指出 Z(x) 为什么能消掉：它是同一提示下的平移，而 D1 已经证明 BT 看不见这种平移。
2. 写出 DPO 的梯度，并解释权重 σ(r̂_l − r̂_w)。给定四个 log 概率，能算出隐式奖励、损失和权重。
3. 说出 β 和参考模型各自的作用，预测 β 变小会怎样；能说明不同配方的 β 为什么不能直接比较。
4. 解释"损失在降，被选回答的概率也在降"是怎么发生的（只看差距、共享部分抵消、隐式奖励外推），并能从训练日志诊断似然位移。
5. 给出一套 DPO 的实用配置，每项标明出处：β、学习率、轮数、参考模型 log 概率预计算、要监控的指标。

### 要解开的误解

| 误区 | 证据 | 出处 |
|---|---|---|
| `dpo-no-kl` | DPO 优化的是同一个带 KL 约束的目标：β 就是 KL 的强度，参考模型定义了隐式奖励 | [RP§3.6]；推导 |
| `dpo-raises-chosen` | 损失只看差距，被选和被拒的概率可以一起下降；而且被选和被拒越相似，越严重 | Smaug 2402.13228 [RP§2]；Razin et al. 2410.08847 [RT§5] |

| `beta-comparable` | Llama 3 用 β = 0.1，Tülu 3 用长度归一化的 DPO、β = 5，两者的尺度相差一个"回答长度"的因子 | [RT§5] |

### 推导全文

#### ① DPO 损失（derive，第 3 段）

出发点（D2）：对每个 x，$\max_\pi \mathbb E_\pi[r] - \beta\,\mathrm{KL}(\pi\|\pi_{ref})$ 的解是
$$\pi_r(y\mid x) = \frac{1}{Z(x)}\,\pi_{ref}(y\mid x)\,e^{r(x,y)/\beta},\qquad Z(x) = \sum_y \pi_{ref}(y\mid x)\,e^{r(x,y)/\beta}$$

**第 1 步** $$\log\pi_r(y\mid x) = \log\pi_{ref}(y\mid x) + \frac{r(x,y)}{\beta} - \log Z(x)$$
*为什么：* 对两边取对数，乘积变成求和，r 就能单独分离出来。

**第 2 步** $$r(x,y) = \beta\log\frac{\pi_r(y\mid x)}{\pi_{ref}(y\mid x)} + \beta\log Z(x)$$
*为什么：* 移项。含义：任何奖励都可以写成"它的最优策略相对参考模型的 log 比 × β"，再加一个只和提示有关的项。

**第 3 步** $$P(y_w\succ y_l\mid x) = \sigma\big(r(x,y_w) - r(x,y_l)\big)$$
*为什么：* 这是 D1 的 Bradley–Terry 模型。

**第 4 步** $$= \sigma\Big(\beta\log\frac{\pi_r(y_w|x)}{\pi_{ref}(y_w|x)} + \cancel{\beta\log Z(x)} - \beta\log\frac{\pi_r(y_l|x)}{\pi_{ref}(y_l|x)} - \cancel{\beta\log Z(x)}\Big)$$
*为什么：* 两个回答属于同一个提示 x，β·log Z(x) 完全相同，相减就没了。这正是 D1 的平移不变：只依赖提示的偏移，BT 看不见。**算不出来的 Z，根本不需要算。**

**第 5 步** $$P(y_w\succ y_l\mid x) = \sigma\Big(\beta\log\frac{\pi_r(y_w|x)}{\pi_{ref}(y_w|x)} - \beta\log\frac{\pi_r(y_l|x)}{\pi_{ref}(y_l|x)}\Big)$$
*为什么：* 偏好概率已经完全用策略来表示，奖励不再出现。

**第 6 步** 不再先学 r、再解出 π，而是直接学 π_θ，并定义**隐式奖励**
$$\hat r_\theta(x,y) = \beta\log\frac{\pi_\theta(y\mid x)}{\pi_{ref}(y\mid x)}$$
在偏好数据上做最大似然，这和 D1 第 4 步是同一个 BT 损失，只是把 r_φ 换成了 r̂_θ：
$$\boxed{\mathcal L_{DPO}(\theta) = -\,\mathbb E_{(x,y_w,y_l)\sim\mathcal D}\Big[\log\sigma\Big(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\Big)\Big]}$$
*为什么可以这样做：* 每个 π_θ 恰好是它自己的隐式奖励 r̂_θ 的最优策略。把 r̂_θ 代回 π\* 的公式：π_ref·e^{r̂_θ/β} = π_θ，所以 Z = Σπ_θ = 1，π\* = π_θ。于是"拟合奖励"和"求最优策略"合成了一步（论文标题："你的语言模型其实是一个奖励模型"）。

**第 7 步（折叠：假设了什么，又丢了什么）**
- 假设 BT 是对的；
- 隐式奖励只确定到"相差一个依赖 x 的常数"，这无所谓；
- 数据有限且离线时，损失对数据里没有的回答不施加任何约束，这就是世界 `dpo_gap_plane` 里 y_3 的来历；
- β 就是 KL 目标里的那个 β。

**填空：** $\mathcal L = -\mathbb E\log\sigma\big(\beta\log\frac{\pi_\theta(y_w)}{\pi_{ref}(y_w)} - \_\_\_\_\big)$，答案是 $\beta\log\frac{\pi_\theta(y_l)}{\pi_{ref}(y_l)}$。

#### ② DPO 的梯度（derive，第 6 段）

记 $u = \hat r_w - \hat r_l$。

**第 1 步** $$\nabla_\theta\mathcal L = -\mathbb E\big[\nabla_\theta\log\sigma(u)\big] = -\mathbb E\big[\sigma(-u)\,\nabla_\theta u\big]$$
*为什么：* $\frac{d}{du}\log\sigma(u) = \frac{\sigma(u)\sigma(-u)}{\sigma(u)} = \sigma(-u)$，与 D1 第 5 步相同。

**第 2 步** $$\nabla_\theta u = \beta\big(\nabla_\theta\log\pi_\theta(y_w|x) - \nabla_\theta\log\pi_\theta(y_l|x)\big)$$
*为什么：* π_ref 是冻结的，log π_ref 对 θ 是常数，求导后消失。所以**参考模型只出现在权重里，不影响更新方向**。

**第 3 步** $$\nabla_\theta\mathcal L = -\beta\,\mathbb E\Big[\underbrace{\sigma(\hat r_l - \hat r_w)}_{\text{排错时大}}\big(\nabla\log\pi_\theta(y_w|x) - \nabla\log\pi_\theta(y_l|x)\big)\Big]$$
*为什么：* σ(−u) = σ(r̂_l − r̂_w)。读法：梯度下降会提高 log π(y_w)、压低 log π(y_l)；隐式奖励排错的对权重接近 1，已经以大差距排对的对权重接近 0 [RT§5]。DPO 论文指出，去掉这个权重的朴素版本会让模型退化〔标准，2305.18290 §4〕。

**第 4 步（逐 token）** $\log\pi(y) = \sum_t \log\pi(y_t\mid x, y_{<t})$。如果 y_w 和 y_l 共享前缀 y_{<k}，那么 t < k 的各项在两边完全相同（同样的上下文、同样的 token），在 ∇log π(y_w) − ∇log π(y_l) 中**正好抵消**。只有分叉之后的 token 得到梯度。
*为什么重要：* 分叉之后，即使两边出现同样的词，上下文也不同了，所以不会抵消。"方向上抵消"也不等于"两边概率都不变"：这一步更新的是共享参数（隐藏层、输出层），共享部分的概率照样会被带着变。这就是似然位移的入口。

**第 5 步（对上世界：为什么 E_π[φ] 会消掉）** 在对数线性玩具里，$\nabla_\theta\log\pi_\theta(y) = \varphi(y) - \mathbb E_{\pi_\theta}[\varphi]$，所以 $\nabla_\theta u = \beta(\varphi_w - \varphi_l)$：期望项消掉，更新方向恒为 d = φ_w − φ_l。于是 θ_t = c_t·d，
$$\pi_t(y) \propto \pi_{ref}(y)\,e^{c_t\,d\cdot\varphi(y)},\qquad \frac{d\log\pi_t(y_w)}{dc} = d\cdot\varphi_w - \mathbb E_{\pi_t}[d\cdot\varphi]$$
一旦比 y_w 更"沿着 d"的回答（玩具中 y_3 的 d·φ = 0.75，而 y_w 只有 0.25）分到足够的概率，y_w 的概率就开始下降。
*为什么讲这一步：* 它把"位移"从一个奇怪的现象，变成 D2 闭式解的一个推论：DPO 也是一种倾斜，倾斜方向由样本对的差决定。

```python
def seq_logp(logits, labels, mask):          # logits [B,T,V]，labels [B,T]，mask 只在回答 token 上为 1
    lp = logits.log_softmax(-1).gather(-1, labels.unsqueeze(-1)).squeeze(-1)   # [B,T]
    return (lp * mask).sum(-1)                                                   # [B]：log π(y|x)

def dpo_loss(pi_w, pi_l, ref_w, ref_l, beta=0.1):   # 四个都是 [B]；ref_* 来自冻结的参考模型
    r_w = beta * (pi_w - ref_w)                       # 隐式奖励
    r_l = beta * (pi_l - ref_l)
    loss = -F.logsigmoid(r_w - r_l).mean()            # 与 D1 的 bt_loss 是同一行
    return loss, r_w.detach(), r_l.detach()           # 后两个只用于记录日志
```

- 和 C-D1-1 并排放：唯一的区别是"奖励从哪来"。
- 参考模型的前向放在 `torch.no_grad()` 里，或者整份数据预先算好。
- 用求和而不是平均，就是标准 DPO；改成除以长度，就是 Tülu 3 的长度归一化版本，β 的尺度随之改变。

### 检验题

1. **计算**（三问，number）：β = 0.1。log π_θ(y_w) = −40，log π_ref(y_w) = −42，log π_θ(y_l) = −55，log π_ref(y_l) = −50。
   - (a) r̂_w 和 r̂_l 各是多少？答 0.2 和 −0.5。
   - (b) 损失是多少？答 0.403（容差 0.005）。
   - (c) 这一对的梯度权重是多少？答 σ(−0.7) ≈ 0.332。
   - 判分要点：(a) 若答 2 和 −5，说明忘了乘 β；(b) 若答 0.597，是把 σ(0.7) 当成了损失。
2. **诊断**（choice，再加一句解释）：在只差几个词的拒答对上做 DPO，300 步内的日志如下——
   - `rewards/accuracies` 从 0.50 升到 0.97；
   - `rewards/margins` 从 0 升到 9；
   - `logps/chosen` 从 −180 降到 −260；
   - `logps/rejected` 从 −190 降到 −330；
   - 在留出的有害提示上，拒答率从 74% 降到 40%。

   发生了什么？怎么办？
   - 答：似然位移，同时也在过拟合。被选和被拒高度相似，两者的概率一起下降，概率流向了"照做"这类回答。
   - 对策：按相似度（CHES）过滤样本对；在被选回答上加 NLL 项；用 DPOP；减少步数或降低学习率；重新构造差别更大的被拒回答。
   - 判分要点：必须指出 `logps/chosen` 下降是关键证据，并且对策里至少有一条针对"相似对"。只说"过拟合"给一半分（`dpo-metrics-good`）。
3. **预测**（choice）：同样的数据，把 β 从 0.1 改成 0.01，最可能发生什么？
   - 选项：①策略离参考模型更远，KL 更大，退化风险更高 ✓；②更贴近参考模型；③没有影响，β 只是损失的缩放。
   - ③标记 `dpo-no-kl`，反馈："β 就是 KL 的强度。β 小，同样的差距需要更大的 log 比来实现。"
4. **选择**（choice）："Tülu 3 的 β = 5 是 Llama 3 的 50 倍，所以 Tülu 3 的缰绳紧得多。"这句话对吗？
   - 答：不对。Tülu 3 用的是长度归一化的隐式奖励 (β/|y|)·log 比，尺度相差一个回答长度的因子。粗算：若 |y| ≈ 250，相当于未归一化时 β ≈ 0.02（这是作者的粗略换算，不是论文结论）。
   - 错选标记 `beta-comparable`。
5. **解释**（由 AI 判读）："DPO 没有奖励模型，所以也没有 KL 约束。"指出这句话错在哪。
   - 要点：DPO 解的是同一个带 KL 约束的目标；β 就是 KL 强度；参考模型定义了隐式奖励的零点。

### "怎么选"卡片（D3）

- **决策图节点：** DM-B3。场景调用 `decision_map({ upto: 'D3', highlight: ['DM-B3'] })`。
- **规则：**
  - 如果有离线的成对偏好（最好从自己的 SFT 模型采样），又不想维护奖励模型和在线采样，就用 DPO。
  - β 决定能离参考模型多远：从 β = 0.1、1 轮开始；训练时同时监控被选回答的 log 概率（`logps/chosen`）。
  - 显存紧时，预先算好参考 log 概率，训练时只需一个模型。托管平台上也能直接用（OpenAI、Vertex、Azure、Together [RA§5]）。
- **反例：**
  - 用两个回答几乎一样的偏好对训练"拒答"。错在：会发生似然位移，拒答率反而从 74.4% 降到 33.4%（Razin et al. [RT§5]）。应该先按相似度过滤，或者加 NLL 项。
- **补充：** 需要模型在自己的输出上持续超越数据，或者奖励可以验证，就走在线强化学习或 RLVR（D2、E1）。前沿配方里，DPO 已经退居"轻量收尾"（Llama 4）[RA§5]。
- **用到这张卡的检验题：** 第 2 题。

### 推导全文：为什么需要"有限的目标差距"（derive，第 3 段）

**第 1 步** 如果某一对的偏好是确定的（y_w 永远赢），这一对的 DPO 损失 −log σ(βh) 只有在 h → ∞ 时才趋于 0（D1 第 6 步）。
*为什么：* h → ∞ 意味着 π(y_l)/π_ref(y_l) 相对 π(y_w)/π_ref(y_w) 趋于 0。不论 β 取多少都是如此，β 只改变走的速度。所以在这一对上，KL 缰绳实际上不起作用了。这正是 IPO 论文的论点 [RT§5]。

**第 2 步（IPO）** 把损失换成 $(h - \tfrac{1}{2\tau})^2$，它在 $h^* = \tfrac{1}{2\tau}$ 处取到最小值，是有限的。
*为什么：* 平方损失回归到一个固定目标；τ 起的作用和 β 类似：τ 越大，目标差距越小，策略越贴近参考模型。TRL 中用 `beta` 参数来传 τ〔待核实〕。

**第 3 步（标签平滑）** 假设每个标签有 ε 的概率是反的：$\mathcal L = -(1-\varepsilon)\log\sigma(\beta h) - \varepsilon\log\sigma(-\beta h)$。对 h 求导并令其为 0：$-(1-\varepsilon)\beta\,\sigma(-\beta h) + \varepsilon\beta\,\sigma(\beta h) = 0 \Rightarrow \sigma(\beta h^*) = 1-\varepsilon$，所以
$$h^* = \frac{1}{\beta}\ln\frac{1-\varepsilon}{\varepsilon}$$
例如 ε = 0.1 时，h\* ≈ 2.2/β。
*为什么：* 承认标签有噪声，就不会去追求无穷大的差距。

**第 4 步（它们修不了什么）** 在 D3 的玩具里（同一对相似样本，训练 400 步）：IPO（目标 h = 1）在 h = 1 处停下，被选回答的概率是 0.22，但有害的 y_3 仍从 0.05 涨到了 0.40；DPO 加 NLL（α = 0.5）则把被选回答保持在 0.92。〔模拟，已验证〕
*为什么：* IPO 和标签平滑限制的是"走多远"；方向仍然是 φ_w − φ_l。NLL 项改变的是方向本身（多了一项 φ_w − E_π[φ]）。

**填空：** IPO 的最优差距 h\* = ____，答案是 1/(2τ)。

C-D4-2（代码页；`judge` 和 `similar` 在右栏单独讲解）：

```python
from vllm import LLM, SamplingParams

policy = LLM("my-sft-model")                                  # 从自己的 SFT 模型采样：在线（同策略）
outs = policy.generate(prompts, SamplingParams(n=4, temperature=0.8, max_tokens=1024))

def prefer(prompt, a, b):                                     # 评委按评分细则比较，交换位置各评一次
    first, second = judge(prompt, a, b), judge(prompt, b, a)  # 各返回 "1" 或 "2"
    if first == "1" and second == "2": return a, b
    if first == "2" and second == "1": return b, a
    return None                                               # 两次不一致：位置偏差或平局，丢弃

pairs = []
for p, o in zip(prompts, outs):
    cands = [c.text for c in o.outputs if c.finish_reason == "stop"]   # 丢掉被截断的回答
    if len(cands) < 2: continue
    res = prefer(p, cands[0], cands[1])        # 实际可做循环赛，再取最好和最差
    if res is None: continue
    chosen, rejected = res
    if similar(chosen, rejected) > 0.9: continue                 # 近似重复：有位移风险（D3）
    pairs.append({"prompt": p, "chosen": chosen, "rejected": rejected})

longer = sum(len(x["chosen"]) > len(x["rejected"]) for x in pairs) / len(pairs)
print(f"被选回答更长的比例：{longer:.0%}")                      # 远高于 50% 就要配平
```

### 检验题

1. **选择**（choice）：你只有线上用户的点赞和点踩（单条回答，加上好或坏），没有成对数据。首选哪一种？
   - 选项：①DPO；②KTO ✓；③SimPO；④PPO。
   - 反馈：①需要成对数据（除非你先按提示把好和坏的回答配对，这也可行，但会丢掉没法配对的数据）；③④不针对这种数据形态。
2. **预测**（choice）：被选回答来自 32B 模型，被拒回答来自 0.6B 模型。已知用这些被选回答做 SFT 会让学生模型变差。在这些对上做 DPO 呢？
   - 选项：①变好 ✓；②同样变差；③没有影响。
   - 解释（由 AI 判读）：DPO 学的是两者的差，不要求被选回答完美；SFT 会把被选回答的缺点（比如超出学生模型能力的写法）一起学进去 [RT§5]。
   - 选②标记 `chosen-must-be-great`。
3. **诊断**（choice，再加一句解释）：用评委标注的对做 DPO 后，对 SFT 模型的胜率涨了 12 个点；平均长度变为原来的 1.9 倍；长度受控胜率只涨了 1 个点；数据里被选回答更长的比例是 78%。
   - 答：长度偏差，数据和评委都偏爱长回答，所以提升主要来自长度。
   - 对策：长度配平；用长度归一化的 DPO；评委细则里明确"简洁优先"；以长度受控的指标为准。
   - 判分要点：必须引用 78% 和"长度受控胜率只涨 1 个点"两条证据。
4. **选择**（四个场景，每个写出方法、数据和风险，由 AI 按要点判读）：
   - (a) 生成 SQL，可以在测试库上执行并比对结果 → RLVR（或者先做拒绝采样加 SFT）；风险是验证器有漏洞，比如结果碰巧相同。
   - (b) 品牌语气，有 2 万条用户偏好对，只有一张卡 → DPO 加 LoRA，预计算参考 log 概率；风险是长度和似然位移。
   - (c) 让模型输出固定的内部 JSON 字段，有 3 千条正确示例 → SFT，或者先试提示词加结构化输出；用偏好或 RL 都是浪费。
   - (d) 已有一个 DPO 模型，对话质量停滞，有强评委和一个集群 → 迭代 DPO，或者在线 RL 加评委（GRPO 类）；风险是奖励投机，要用独立评估来停。
   - 判分要点：每个场景三项（方法、数据、风险）齐全才给满分；(c) 若选偏好学习或 RL 要扣分，因为能示范的格式问题用 SFT 或提示词就够了（D1 卡片的反例）。
5. **解释与设计**（由 AI 按评分细则判读）：为一个客服模型设计偏好数据管线。评分细则共 7 点，答到 5 点算通过：
   1. 提示来自真实分布，并去重、去污染；
   2. 从自己的 SFT 模型做在线（同策略）采样，每个提示 4–8 个回答；
   3. 评委使用写明政策的评分细则；
   4. 交换位置评两次，丢掉不一致的；
   5. 过滤平局、近似重复，配平长度；
   6. 用一小批人工标注校准评委；
   7. 留出集评估，并迭代。
